# Nest & Yard

Katalog produktów premium kierujący klientów do konkretnych ofert Allegro, z panelem operacyjnym dla sprzedaży.

Projekt Next.js obejmuje katalog produktów, panel administratora, statystyki sprzedaży, zamówienia Allegro, generator faktur, kontrolę stanów i przygotowaną integrację OAuth Allegro.

Szczegółowa dokumentacja zostanie dodana w kolejnym commicie inicjalizującym projekt.
